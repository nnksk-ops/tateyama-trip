08行程案の比較（叩き台）

採用はKeIさんが決める前提で、候補をどう繋ぐと成立するかだけ示します。最大の分岐は「山の上に泊まるか、麓に泊まるか」です。

案① 王道・室堂泊 ─ 3,000mと最高所温泉を両取り

  1. 1日目 4:00 大津京発 → 北陸道 → 立山駅（休憩込み約5時間）
  2. 9:30 WEBきっぷで指定便に乗車 → 室堂 11:00頃着（往復8,180円）
  3. 午後 室堂平周遊（みくりが池・地獄谷展望・雷鳥探し）→ 雷鳥沢ヒュッテ or みくりが池温泉へ
  4. 夕 日本最高所の温泉 → 標高2,400mの星空
  5. 2日目 5:00 一ノ越→雄山→大汝山→富士ノ折立→雷鳥沢の周回（約6時間）
  6. 13:00 下山後もう一度温泉 → バス・ケーブルで立山駅
  7. 16:00 立山町 or 富山市街で富山ブラック／回転寿司 → 帰路

案② 穴場・大日小屋泊 ─ 剱岳の特等席とランプの宿【ランクS】

  1. 1日目 早朝 大津京発 → 立山駅 → 室堂（午前中に入るのが絶対条件）
  2. 昼 室堂 → 新室堂乗越 → 奥大日岳 → 大日小屋（約8時間）
  3. 夜 ランプの灯りとアコースティックギター。正面に剱岳
  4. 2日目 6:00 大日岳 → 大日平（木道）→ 大日坂を下って称名滝（約4時間）
  5. 昼 称名滝を見て立山駅へ → 千寿の湯 or 吉峰温泉で汗を流す
  6. 午後 鮨処板はし or 富山市街 → 帰路

※前夜に千寿荘（ケーブル乗場から徒歩30秒）に泊まって始発を取る「前泊化」が最も確実な保険になります。

案③ 混雑完全回避 ─ 弥陀ヶ原＋世界遺産＋花火

  1. 1日目 大津京発 → 東海北陸道経由で五箇山 菅沼集落（相倉より静か）
  2. 午後 立山山麓へ移動。大辻山を軽く登る or 立山カルデラ砂防博物館
  3. 夕 千寿荘 or グリーンビュー立山（千寿の湯）泊 → 猿倉山の花火 19:20 も射程
  4. 2日目 朝 立山駅 → 弥陀ヶ原（室堂より安く空いている）で木道 外回り1時間20分
  5. 昼 下山 → 称名滝展望台（往復1時間30分）
  6. 午後 立山吉峰温泉ゆ〜ランド → 新湊きっときと市場で白えび → 帰路
4人パーティで効いてくる実務メモ
  • 山小屋・アルペンルートともに8月の土曜は最も予約が取りにくい枠。宿とWEBきっぷは同時に押さえる。
  • 体力差があるなら「雄山まで登る組（★2）」と「室堂平を歩く組（★1）」に分けても、みくりが池温泉で合流できる。
  • 雷鳥沢ヒュッテの4名個室13,000円/人は4人にきれいに嵌まる数少ない選択肢。
  • 車は立山駅の無料駐車場に置いたままアルペンルートを往復するのが基本形（長野側に抜けるなら車回送を手配）。
  • 大阪組が電車で滋賀合流 → 大津京から1台で行くなら、運転交代を前提に早朝発が現実的。
  • 絶景は午前中にしか手に入らない（午後はガス・夕立）。稜線に立つ時刻を朝に寄せるほど成功率が上がる。
